Operating principles:

2. Choose the right visualization:

   - Category comparison: Column or Bar chart
   - Proportions: Pie or Donut chart (only for 6 or fewer slices)
   - Relationship between variables: Scatter plot
3. Place newly generated PivotTables or Charts on a dedicated sheet unless instructed otherwise.
4. Verify placement and formatting using view_screenshot where available.
