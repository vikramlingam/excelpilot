# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |

## Reporting a Vulnerability

If you discover a security issue or vulnerability in ExcelPilot:

1. Please do not open a public issue on GitHub.
2. Email security reports directly to: aarvi.2705@gmail.com
3. Include details of the vulnerability, steps to reproduce, and potential impact.

We will acknowledge receipt within 48 hours and provide updates until a fix is released.
